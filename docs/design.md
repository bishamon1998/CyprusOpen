# Наброски интерфейса

[Открыть интерактивный эскиз](prototype/index.html). Это автономный файл: можно открыть в браузере без сборки и серверов. Он не обращается к сети и не показывает реальные показатели. Серые полосы обозначают размещение будущих графиков, не значения данных. Переключатель состояний — инструмент просмотра эскиза, в продукт не переносится.

## Экраны

| Экран | Основная задача | Компоновка |
| --- | --- | --- |
| Statistics | Понять два обязательных показателя | Краткое вступление; immigration первым, tourism вторым; фильтры рядом с каждым графиком; единицы, география, источник и дата рядом с данными |
| Parking | Найти парковку и оценить актуальность | Статус обновления; карта/список; выбранная парковка с available/unknown/stale; отсутствие данных не равно «занято» |
| Pharmacies | Понять, что функция ещё не доступна | Coming soon, без расписания, адресов или заявления о дежурстве |
| About | Проверить происхождение данных | Publisher, definition, license, coverage, cadence, последняя успешная синхронизация, ограничения |

Desktop: ограниченная ширина чтения, два графика один под другим, место для полного рейтинга. Mobile: одна колонка, перенос фильтров, горизонтальные бары с читаемыми подписями, список парковок по умолчанию. Карта не должна перехватывать прокрутку всей страницы.

## Визуальное направление

Тёплый светлый фон, тёмный текст, спокойный зелёный акцент, минимум рамок и теней. Системный sans-serif без внешних font-запросов; scale spacing 4/8/12/16/24/32/48, радиусы 8/16, обычный текст от 16 px. Графики не получают отдельный цвет для каждой страны. Предупреждения сопровождаются текстом, не только цветом.

Повторно используем AppShell, LanguageSwitcher, DatasetChart, SourceNote, FreshnessNotice и DataState, когда они реально повторяются. Feature-компоненты остаются рядом со своим экраном. Production использует React, i18next/react-i18next, TanStack Query, ECharts/Leaflet; автономный эскиз их не заменяет.

В эскизе работают навигация, EN/RU/EL с сохранением выбора, просмотр loading/empty/error/stale, карта/список как области компоновки. Годы, seasons, значения и координаты не выдумываются: data-фильтры disabled до подключения метаданных.

Проверка эскиза: `node scripts/check-prototype.cjs` при доступном Playwright и установленном Chrome. Для внешней установки Playwright можно задать `PLAYWRIGHT_MODULE_PATH`; `PROTOTYPE_SCREENSHOT_DIR` включает сохранение desktop/mobile PNG. Это локальная браузерная проверка, без запросов к внешним сайтам. В первой проверке прошли 60 сочетаний: 4 экрана × 3 языка × 5 ширин (320/375/390/768/1280), первый визит EN при RU browser locale, сохранение языка, пять состояний данных и карта/список. Desktop и mobile также просмотрены визуально. Проверка дизайна не заменяет сквозные тесты будущего приложения с backend.
