# План реализации

Цель MVP: два правдиво подписанных графика на первой странице и парковки с понятной свежестью. EN/RU/EL и мобильная версия входят в каждый frontend-этап. Оценки сроков появятся после проверки источников: основной риск — состав и доступность официальных данных.

## Текущее состояние

- [x] GitHub `bishamon1998/CyprusOpen`, `main`, первый push проверен.
- [x] PostgreSQL: две базы, роли, схемы; четыре интеграционные проверки прошли.
- [x] План, архитектура, черновики API и экранов.
- [ ] Точные источники двух графиков и live parking полностью проверены.
- [ ] Приложения, импорты, CI, Wiki и Railway deployment реализованы.

## Этапы

| Этап | Работа | Условие завершения |
| --- | --- | --- |
| 0. Источники | Для immigration, tourism, parking проверить ресурс, поля, периоды, смысл, географию, лицензию и ограничения | В `data-sources.md` есть доказательства и разрешённая политика запросов; неподходящий набор не подменён похожим |
| 1. Каркас | Два Spring Boot приложения, минимальный common JAR, Maven Wrapper, React/Vite, i18next, proxy, Dockerfiles, health и CI | Независимые сборки; Compose; frontend на трёх языках; внешний fetch выключен |
| 2a. Иммиграция | Liquibase + DBML, отдельный importer, рейтинг стран и выбор года | Идемпотентность и откат проверены; API читает БД. Если страны недоступны, этап ждёт решения по источнику |
| 2b. Туризм | Помесячный импорт, рейтинг и сезоны, полные/неполные периоды | Проверены пропуски и зимний переход года; оба графика на первой странице; определения точны |
| 3. Парковки | Adapter, разрешённое расписание, Caffeine, карта/список, stale/unknown/unavailable | Проверены первый запуск, refresh, 429/ошибка, пропавшая запись и возраст снимка; посетители не вызывают upstream |
| 4. Релиз | Атрибуция, mobile/a11y, документация, Wiki sync, Railway настройки | CI проходит; production-конфигурация проверена; Wiki опубликован или блокер указан; выкладка после отдельного разрешения |
| Позже | Дежурные аптеки отдельным сервисом | Проверено расписание дежурств, не просто список аптек |

Этап 1 может идти при незавершённом этапе 0: health, навигация, явно обозначенные локальные fixtures. Этапы 2a/2b и 3 зависят от своих источников, не от завершения друг друга. Отсутствие immigration не блокирует каркас, но не позволяет объявить Statistics MVP готовым.

## Ближайшие изменения

1. Завершить ручную проверку трёх источников с малым числом запросов. Выяснить, опубликованы ли отдельные страны предыдущего проживания для immigration, а не только гражданство или регион.
2. Зафиксировать Maven/Boot/dependency версии; добавить два health-only приложения. JPA/Liquibase подключать там, где есть реальные таблицы; Parking не требует БД для выдачи снимка.
3. Добавить frontend с четырьмя маршрутами. Перенести решения из [эскиза](prototype/index.html), а не его демонстрационную реализацию.
4. Добавить независимые CI jobs и `SpringBootTest + Testcontainers`. Изменение common/build config запускает обе backend-проверки.
5. Пройти путь одного проверенного набора от ресурса до API/графика, затем добавить второй. После этапа — review diff, проверки, commit, push, сверка remote.

## Приёмка

| Область | Проверка |
| --- | --- |
| Данные | PostgreSQL и Liquibase; повторный импорт; исправленная история; откат; missing не равен zero |
| Upstream | Локальный HTTP stub; timeout, 429/Retry-After, предел тела/запросов; ноль госзапросов в CI |
| UI | Два графика; фильтры из метаданных; loading/empty/error; stale; список при недоступной карте |
| Языки | Первый визит EN при любом browser locale; EN/RU/EL, сохранение выбора; Intl |
| Mobile | 320, 375, 390, 768, 1280 CSS px; длинные RU/EL строки; keyboard/focus; touch targets от 44 px |
| Деплой | Независимая сборка, build context, health, private DB, один scheduler на host, откат |

Только интеграционные и несколько сквозных тестов. Без unit-тестов, object mocks, тестов на живых государственных endpoints и тестов ради покрытия.

## Открытые вопросы

| Вопрос | Начальное состояние |
| --- | --- |
| Нужная детализация immigration | Не заменяем потоки гражданством; показываем отсутствие набора |
| Доступ к live parking и время наблюдения | Нет счётчиков свободных мест, fetch выключен |
| Частоты запросов и контакт проекта | Scheduler выключен |
| Подложка карты и условия провайдера | В эскизе только область карты; список полноценный |
| Wiki initialized + credentials | Документация в `docs/`, публикация ожидает настройки |
| Railway project, домен и бюджет | Только проект конфигурации, без создания ресурсов |
